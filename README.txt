かんきつ学習画像カメラ v3

使い方
1. このフォルダをHTTPS対応の静的ホスティング（GitHub Pages / Netlifyなど）へアップロードします。
2. iPhone SafariでURLを開き、カメラへのアクセスを許可します。
3. 品種・果実ID・撮影角度を選び、シャッターで連続撮影します。
4. 50枚（変更可能）ごとにZIPを書き出し、iPhoneの「ファイル」で保存・解凍を確認します。
5. 確認後のみ、端末内の撮影済み画像を削除してください。

注意
・撮影画像はIndexedDBに保存されます。iOSによるストレージ消去、ブラウザデータ削除、端末故障などに備えて定期的にZIPを保存してください。
・ZIPは無圧縮格納です。JPEG画像自体は撮影時に圧縮されるため、ZIPの容量は画像合計とほぼ同じです。
・ZIP書き出しは1回最大50枚または100枚で、古い画像から選びます。
・HTTPS接続（または開発用localhost）が必要です。ローカルのHTMLファイルを直接開くとカメラが使えないことがあります。
・撮影画面はiPhone Safariの実機での動作検証をまだ行っていません。
